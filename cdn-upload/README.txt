================================================================================
  照片/音乐 CDN 上传说明（必做，否则体验版画廊图加载不出来）
================================================================================

小程序主包只保留封面（约 80KB），14 张画廊图 + 音乐放在 GitHub，
通过微信「downloadFile 合法域名」加载。

【第一步】把本文件夹推到 GitHub 仓库 91qin/marry
--------------------------------------------------------------------------------
在电脑命令行执行（仓库路径按你实际情况改）：

  cd D:\hwl
  git clone https://github.com/91qin/marry.git marry-repo
  xcopy /E /I cdn-upload marry-repo\cdn-upload
  cd marry-repo
  git add cdn-upload
  git commit -m "上传婚礼画廊与音乐 CDN 资源"
  git push

推送后等 1～3 分钟 CDN 生效。

浏览器测试（能打开图片说明成功）：
  https://cdn.jsdelivr.net/gh/91qin/marry@main/cdn-upload/gallery/1.jpg

【第二步】微信公众平台配置域名
--------------------------------------------------------------------------------
登录 mp.weixin.qq.com → 开发管理 → 开发设置 → 服务器域名

在「downloadFile 合法域名」添加：
  https://cdn.jsdelivr.net
  https://91qin.github.io

（request 合法域名里已有 Supabase 即可）

保存后，重新上传小程序代码。

【第三步】重新上传体验版
--------------------------------------------------------------------------------
开发者工具 → 上传 → 公众平台设为体验版 → 手机删除旧版后重新扫码
